# Data Privacy & Cryptography Practicals

This repository contains solutions for practical exercises on basic cryptography, password security, data privacy, and ethics.

## Contents

1. `CaesarCipher.py` – Caesar cipher encryption/decryption.
2. `RailFence.py` – Rail Fence cipher encryption/decryption.
3. `SHA256.py` – SHA-256 password hashing.
4. `CheckPwned.py` – Check leaked passwords via Have I Been Pwned.
5. `RandomPassword.py` – Generate passphrase-style passwords from dictionary words.
6. `BruteForceAttack.py` – Simulated brute-force attack on simple passwords.
7. `DigitalSignature.py` – Demo of digitally signing and verifying a document.
8. `08_DataPrivacyAudit.md` – Data privacy audit of an organization.
9. `09_DataProtectionPlan.md` – Data protection compliance plan.
10. `10_DataPrivacyEthics.md` – Ethical considerations in data privacy.
